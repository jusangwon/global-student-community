# 🌐 [서비스명 미정] 외국인 유학생 다국어 정보·소통·지역탐방 플랫폼
> **외국인 유학생의 정보 접근성 · 사회적 연결 · 지역사회 참여를 하나의 이용 흐름으로 지원하는 통합 플랫폼 (MVP 파일럿 버전)**
>
> *※ 본 프로젝트의 최종 서비스 명칭은 사용자 조사 및 파일럿 테스트를 거쳐 확정할 예정입니다. 초기 기획안 원안에서는 가칭인 `K-Nest`로 표기되어 있습니다.*

---

## 1. 기획 배경 및 해결하고자 하는 문제

한국에서 공부하는 외국인 유학생은 학업과 동시에 새로운 언어, 행정 제도, 주거·교통·의료·식생활 환경, 사회적 관계에 적응해야 합니다. 그러나 필요한 정보가 대학 홈페이지, 국제처 공지, 공공기관, SNS, 메신저 단체방 등에 흩어져 있어 탐색 부담이 크고, 언어 장벽으로 인해 질문이나 도움 요청을 망설이는 경우가 많습니다.

본 플랫폼은 유학생의 적응을 개인의 노력에만 맡기지 않고, **정보 접근성 · 사회적 연결 · 지역사회 참여**를 하나의 이용 흐름 안에서 지원하는 보완적 플랫폼을 지향합니다.

### 핵심 문제 가설 (검증 과제)
1. **정보 탐색의 분산:** 학교·생활 정보가 여러 채널에 나뉘어 있어 필요한 정보를 찾기 어렵다.
2. **정보 신뢰성 판단의 어려움:** 공식 안내와 개인 경험, 오래된 게시물이 혼재되어 있다.
3. **질문과 도움 요청의 장벽:** 누구에게 무엇을 물어야 할지 모르거나 언어·관계의 장벽으로 질문을 망설인다.
4. **지원 자원 및 지역 연결의 부족:** 대학 및 지역사회(식당, 문화시설, 축제 등)의 자원을 알지 못해 이용하지 못한다.

## 2. 통계적 배경 및 학술적 근거

### 📊 국내 외국인 유학생 규모 (2026년 교육기본통계)
- 국내 고등교육기관 외국인 유학생 수는 **307,464명**으로 전년 대비 **54,030명(21.3%) 증가** (학위과정 72.6%, 비학위과정 27.4%)
- 주요 출신국: 베트남(31.5%), 중국(25.7%), 우즈베키스탄(6.8%), 네팔(6.5%), 몽골(5.6%) 등 다국적화 진행
- 교육부 **「Study Korea 300K Project」** 등 유학생 유치 이후 학업·생활·정주 단계의 지원 중요성 확대

## 3. 현재 구현된 주요 기능 (파일럿 확인 가능 항목)

### ① 12개 국적 기반 다국어 UI & 실시간 AI 번역 게시판 (`#board`)
- **지원 국적 및 언어 (12종):** 한국(`ko`), 미국/영어권(`en`), 중국(`zh`), 일본(`ja`), 베트남(`vi`), 몽골(`mn`), 러시아(`ru`), 스페인어권(`es`), 프랑스어권(`fr`), 태국(`th`), 인도네시아(`id`), 우즈베키스탄(`uz`)
- **국가별 유학 준비 게시판 (`✈️ 유학 준비 게시판` — 한국·미국·중국·일본):**
  - 아직 유학을 오지 않은 **유학 준비생(미인증 상태)**도 별도 인증 없이 가입·참여하여 출국 전 비자, 기숙사, 어학 시험, 현지 정착 정보를 자유롭게 질문하고 소통할 수 있습니다.
  - 이미 재학 인증을 마친 유학생(`✓ 재학 인증`)과 유학을 다녀온 선배(`🎓 유학 선배`)가 작은 인증 뱃지를 달고 신뢰도 높은 조언과 댓글을 남길 수 있습니다.
- **토큰 절약형 하이브리드 번역:** 고정된 메뉴·버튼·태그·안내 문구는 **12개 언어 기본 내장 사전**으로 즉시 전환되며, 사용자가 직접 작성한 게시글·댓글·장소 후기에만 **Gemini API 번역**을 호출합니다.
- **간결한 글쓰기 경험:**
  - 게시판 구분(`일반 캠퍼스 게시판` vs `한국/미국/중국/일본 유학 준비 게시판`) 및 기본 카테고리 **자유게시판(`자유`)** 선택 지원
  - 본문 입력란 내 `#해시태그` 작성 시 자동 추출·등록
  - 본문 우측 하단 **`익명으로 쓰기`** 체크박스 및 게시물 신고(누적 시 자동 숨김) 기능

### ② 동네 탐방 — 주변 가게·유원지·기념관·축제 지도 및 다중 후기 (`#map`)
- **반경 선택 & 정렬 필터:** 캠퍼스(경상국립대 가좌캠퍼스 기준점) 중심 **`1km 이내(기본값)` / `5km 이내` / `15km 이내` / `30km 이내`** 반경 선택 및 **`가까운 순` / `별점 높은 순` / `후기 많은 순`** 정렬 지원
- **4대 장소 분류:** `식당·카페` / `유원지·명소` / `기념관·전시` / `축제·행사`
- **지도 장소 검색 & 핀 선택:** 오픈소스 Leaflet + OpenStreetMap 연동 (추후 카카오맵/네이버 지도 SDK로 즉시 교체 가능하도록 모듈화)
- **중복 장소 자동 병합 & 다중 후기 누적:** 여러 사용자가 같은 장소에 별점(1~5점), 후기 사진, 평가를 남기면 **하나의 장소 카드 아래에 평균 별점과 여러 사람의 후기가 누적**되며 후기 본문도 다국어로 자동 번역됩니다.

### ③ 한국어 메뉴판 사진 해독(OCR) & 기피 재료 안내 (`#home`)
- 한국어 메뉴판 사진을 찍거나 업로드하면 브라우저 내 OCR(Tesseract.js)로 메뉴 이름을 인식하고, 각 음식의 설명·맵기·가격과 함께 **본인이 먹지 않는 재료(돼지고기, 소고기, 해산물, 우유, 땅콩 등 종교·알레르기·채식 기준)**가 포함된 경우 빨간색 경고를 표시합니다.
- 식당 직원에게 바로 보여줄 수 있는 **한국어 주문 문장 카드**를 함께 제공합니다.

### ④ 통합 스크랩북 및 실시간 검색 (`#saved`)
- 게시판의 **게시물**, 동네 탐방의 **장소**, 메뉴 찾기의 **음식 메뉴**를 모두 스크랩(`☆ 스크랩`)하여 한곳에 모아볼 수 있습니다.
- 유형별 필터(`전체` / `게시물` / `동네 장소` / `메뉴`)와 **실시간 검색창**(제목, 본문, 번역문, `#해시태그`, 장소명, 후기 검색)을 지원합니다.

### ⑤ 내 정보 · 프로필 커스터마이징 · 유학생 인증 뱃지 (`#profile`)
- **프로필 사진 편집:** 기본 프로필 로고(`profile_icon.svg`)가 기본 적용되며, 사용자가 원할 때 직접 프로필 사진을 업로드(정사각형 자동 리사이즈)하거나 기본 로고로 초기화할 수 있습니다.
- **유학생 · 유학 경험자 인증 뱃지 (`✓ 재학 인증` / `🎓 유학 선배`):**
  - 아직 유학을 오지 않은 학생은 미인증(`🌱 유학 준비생`) 상태로 가입·활동이 가능합니다.
  - 내 정보 탭에서 **재학생 인증(`✓ 재학 인증`)** 또는 **유학 경험/졸업 인증(`🎓 유학 선배`)**을 완료하면 프로필 아바타 우측 하단과 닉네임 옆에 작은 인증 뱃지가 부착되어 유학 준비생들에게 신뢰도 있는 멘토링을 제공할 수 있습니다.
- **즉시 언어 전환:** 국적을 변경하고 저장하면 앱 전체 언어와 게시글 번역 언어가 해당 국가 언어로 즉시 전환됩니다.

## 4. 실행 및 클라우드 배포 방법

### A. 로컬 PC에서 실행하기
1. Python 3.8 이상이 설치되어 있어야 합니다.
2. 실시간 AI 번역을 사용하려면 `keys/gemkey` 파일(또는 환경변수 `GEMINI_API_KEY`)에 Gemini API 키를 한 줄로 저장합니다.
3. 아래 명령어로 서버를 실행합니다:
   ```bash
   python server.py
   # Windows에서는 run.bat 더블클릭
   ```
4. 브라우저에서 `http://localhost:8787`로 접속합니다.
5. 외부 인터넷망(모바일 LTE/5G)에서 테스트 링크/QR로 접속하려면 `run-mobile-tunnel.bat`을 실행합니다.

### B. 클라우드 서버 배포 (Render / Railway 등)
1. 본 리포지토리를 GitHub에 푸시합니다.
2. Render.com(또는 Railway.app)에서 **New Web Service**를 생성하고 GitHub 리포지토리를 연결합니다 (`render.yaml` 및 `Procfile` 내장).
3. 환경변수(Environment Variables)에 `GEMINI_API_KEY`를 등록하면 24시간 접속 가능한 테스트 URL이 생성됩니다.

## 5. 윤리적 운영 원칙 및 향후 로드맵

- **정보 신뢰성 구분:** 공식 기관 정보, 운영 검토 정보, 개인의 이용자 경험(후기)을 명확히 구분하며, 비자·법률·의료·금융 등 고위험 주제는 커뮤니티 답변을 확정적 조언으로 제시하지 않고 공식 기관 안내를 우선합니다.
- **향후 계획:** 소규모 파일럿 사용자 테스트 및 인터뷰 → 학교별 공식 공지/체크리스트 연동 → 카카오/네이버 지도 정식 API 전환 → 최종 서비스 명칭 확정
